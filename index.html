Foto-Scan einrichten

Beim Foto-Scan erkennt Claude die Karten auf euren Fotos. Dafür braucht die App einmalig einen Claude-API-Schlüssel.

  1. Auf console.anthropic.com anmelden und unter Billing etwas Guthaben aufladen (5 € reichen für viele Fotos).
  2. Unter API Keys → Create Key einen Schlüssel erstellen und kopieren.
  3. Hier einfügen und speichern.

Der Schlüssel bleibt nur auf diesem Gerät und wird direkt an Claude geschickt. Ein Foto kostet etwa 2–5 Cent.

Legt mehrere Karten nebeneinander auf einen ruhigen Untergrund, ohne Spiegelungen. Name und Nummer unten auf der Karte sollten lesbar sein. Ihr könnt beliebig viele Fotos nacheinander machen, gleiche Karten werden automatisch zusammengezählt.
